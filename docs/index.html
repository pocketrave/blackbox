Blackbox pocketrave mod: patcher

Unofficial mod for the original 1010music Blackbox, built on stock firmware 3.1.9. Features, source and known issues.

  1. Download blackbox 3.1.9 from 1010music.com/downloads and unzip it.
  2. Choose the BLACKBOX.bin from that zip below. Keep the stock file: it is your way back.
  3. Copy the patched file to the root of the microSD card as BLACKBOX.bin and boot the Blackbox holding A+B to install it.
The file is patched in this page. Nothing is uploaded.
